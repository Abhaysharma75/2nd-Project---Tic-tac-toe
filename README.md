# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe web game** built using HTML5, CSS3, and JavaScript.

## ✨ Features

- 🎮 Two-player gameplay
- ❌ Player X vs Player O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart game
- 🎨 Clean and responsive UI
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing! 🎮
